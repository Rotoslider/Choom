Privacy Policy

Choom is a self-hosted application. All data stays on your local machine. No data is collected, shared, or transmitted to third parties.

The exception is whatever you explicitly configure: if you connect an external LLM provider (such as OpenRouter, Anthropic, or OpenAI), the messages you send to that provider travel through it — exactly like any API client.
